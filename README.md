# arogyapath




Arogya Path (Disease Control App)

Arogya Path is a Flutter-based Disease Control and Health Management App designed to simplify healthcare. Users can book doctor appointments, view their reports, get customized precautions, manage medication schedules, order medicines from nearby stores, and stay updated on trending diseases and health news.







🌟 Features
Appointment Booking
Easy scheduling with doctors for checkups and consultations.

Medical Result Reports
View and manage health reports securely.

Doctor's Precaution Advice
Receive customized precautions and advice based on your medical reports.

Medicine List and Reminders
Track medicines with exact timings for consumption.

Order Medicines from Nearby Stores
Fast ordering system, similar to services like Zepto, for urgent medication needs.

Latest Health News Updates
Stay updated with news related to diseases, healthcare, and medicines.

Trending Disease Alerts
Get real-time updates and precautions for trending diseases like COVID-19, heat waves, etc.




🚀 Technologies Used

Frontend: Flutter, Dart
Backend: Firebase (Authentication, Firestore, Cloud Storage)
Real-time Updates: Firebase and News APIs
